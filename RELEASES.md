# Release & Support Matrix

This tracks which `@moodlehq/design-system` major versions are currently supported. It's maintained by hand — not generated by a script — cross-referencing [CHANGELOG.md](CHANGELOG.md), git tags, each major's `peerDependencies`, and (manually) which moodle/moodle branches pin which MDS major.

## Support policy

- **New majors:** a new MDS major version is only cut if a major version of [moodle/moodle](https://github.com/moodle/moodle) specifies that MDS major as a peer dependency.
- **Bug-fix support:** 12 months from a major version's initial release.
- **Security-only support (Non-LTS):** a further 18 months after bug-fix support ends.
- **Security-only support (LTS):** a further 3 years after bug-fix support ends.
- After that window, a version is unsupported and receives no further fixes.
